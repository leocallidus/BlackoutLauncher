# Blackout Launcher

Русский | [English](README.md)

Blackout Launcher — это инструмент для приватности и экономии батареи. Он запускает выбранное приложение и позволяет мгновенно закрыть экран полностью чёрным оверлеем. Оверлей удерживает экран включённым, скрывает системные панели и устанавливает минимальную яркость до выхода.

## Возможности

- Список всех запускаемых приложений (с поиском).
- Запуск целевого приложения и плавающая кнопка затемнения.
- Нажатие на кнопку включает чёрный экран.
- Выход по N нажатиям (настраивается в главном окне).
- Долгое нажатие на кнопку — остановка сервиса.
- Перетаскивание плавающей кнопки.
- Восстановление яркости при выходе и при следующем старте, если сервис был убит.

## Требования

- Android 7.0+ (minSdk 24).
- Разрешение на отображение поверх других приложений.
- Разрешение на изменение системных настроек (яркость).
- Разрешение на вибрацию (вибро‑отклик).

## Разрешения

Задекларированы в `AndroidManifest.xml`:

- `SYSTEM_ALERT_WINDOW` (оверлей)
- `WRITE_SETTINGS` (яркость)
- `QUERY_ALL_PACKAGES` (список приложений)
- `FOREGROUND_SERVICE`
- `FOREGROUND_SERVICE_SPECIAL_USE`
- `VIBRATE`

В приложении есть кнопки для перехода к системным настройкам разрешений.

## Как пользоваться

1. Откройте приложение.
2. Выдайте необходимые разрешения.
3. Выберите приложение.
4. При необходимости задайте “Нажатий для выхода”.
5. Нажмите **Запустить**.
6. В выбранном приложении нажмите на плавающую кнопку, чтобы включить затемнение.
7. Нажмите по чёрному экрану N раз, чтобы выйти.
8. Долгое нажатие на кнопку останавливает сервис.

## Сборка и запуск

Откройте проект в Android Studio и запустите модуль `app` на устройстве или эмуляторе.

## Примечания

- На некоторых устройствах скрытие системных панелей может работать по‑разному.
- Если список приложений выглядит неполным на старом эмуляторе, попробуйте образ с Play Store или более новую версию API.
